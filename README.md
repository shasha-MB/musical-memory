# 🐾 现实版宝可梦 · 城市精灵图鉴

用手机拍下身边真实的小动物，AI 识别 + 自动抠图，生成属于你的精灵图鉴卡！
集齐 **图鉴收集 · 地图标记 · 社区求助 · 宠物医院** 四大玩法。

## ✨ 功能

- 📷 **拍照/相册收服**：只收录真实动物（AI 判定），自动抠图去掉背景
- 🃏 **图鉴卡**：命名、稀有度、可互动的虚拟小伙伴（喂食/抚摸/玩耍）
- 🗺️ **遭遇地图**：每只精灵记录被遇到的地点（腾讯地图，支持手动选点）
- 🆘 **社区求助**：发现受伤的小动物发布求助，他人去捕捉救助
- 🏥 **宠物医院**：资质认证 → 集资救治 → 治疗 → 领养/放生 全流程
- 🔍 **审核后台**：内置 `/admin` 管理页，审核医院资质与集资申请
- ⭐ **高德评分同步**：医院主页可一键从高德地图拉取真实评分

## 🚀 快速开始

只需 Python 3.8+，**零第三方依赖**：

```bash
python 宝可梦.py          # 默认 http://127.0.0.1:8000
python 宝可梦.py 9000     # 指定端口
```

打开浏览器（手机也在同一 WiFi 下直接访问提示的地址）即可使用。
首次运行自动生成示例数据（3 只示例精灵），在 `/admin` 或页面里可以重置。

## 🤖 开启 AI 识别（可选）

不配置 AI 也能玩：拍照后直接按整图抠图、手动命名收服。
配置后可自动判定"是否动物 + 主体位置"，抠图更精准：

```bash
# 阿里云百炼（通义千问 VL），或任何 OpenAI 兼容接口
set DASHSCOPE_API_KEY=sk-xxxx      # Windows
export DASHSCOPE_API_KEY=sk-xxxx   # macOS / Linux
python 宝可梦.py
```

高德评分功能需要高德开放平台 Web服务 Key：在医院工作台点"同步评分"时按提示输入一次即可（保存在服务器 `settings.json`）。

## 📁 文件说明

| 路径 | 说明 |
|---|---|
| `宝可梦.py` | 整个应用（后端 + 前端全部内嵌），单文件即可运行 |
| `data.json` | 运行后生成的数据库（JSON） |
| `uploads/` | 运行后生成的图片目录 |
| `settings.json` | 高德 Key 等设置 |

数据都在本地，备份时拷走 `data.json` + `uploads/` 即可。

## 🧱 技术栈

- 后端：Python 标准库 `http.server`（多线程），REST 风格 `/api/*`
- 前端：原生 HTML/CSS/JS 单页应用（内嵌在 py 里）
- 地图：腾讯位置服务 GL JS
- 抠图：纯前端 Canvas 颜色模型 + 连通块分析，无需服务端算力
